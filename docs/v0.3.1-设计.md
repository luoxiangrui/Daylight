# Daylight 0.3.1 设计规范

主窗口和快速窗口共用 ui/style.css，无外部字体和线上图标依赖。正常阅读以暖白纸面、深灰文字和低饱和绿为主；侧栏、输入区与选中区以明度差区分。日历同时以文字标明种类、时间和重叠，任务用文字或勾选标识状态。

|用途|浅色|深色|
|---|---|---|
|背景／内容／侧栏|#FAF8F2 / #FFFDF8 / #F0EEE5|#242722 / #2B2F29 / #20241F|
|正文／辅助|#353832 / #64695F|#EEEEE5 / #B6BCB0|
|分割线／品牌／选中|#DEDDD2 / #4D6753 / #E7ECDF|#4C5448 / #ACC5A5 / #374436|

success、warning、error、info、disabled、focus、hover、selected 分别表达反馈与交互语义。自动测试覆盖文字、品牌、焦点、禁用和状态色对四种背景的对比度。

字号按用途分层：衬线页面标题 30–44 px，章节标题约 17 px，界面正文 15 px，辅助 13 px，日记正文 17 px、行高 1.95。中文界面优先 Microsoft YaHei UI，标题使用系统衬线，数字明确带单位。写作区最大 38 em，宽屏将空间留给两侧。

基础间距以 4 px 递增；主要控件最小高度 36 px，常规圆角 8 px，重点面板 12 px。月格、热力图及时间轴有专用紧凑尺寸。导航用同一套线形 SVG；键盘焦点采用两像素外描边。

首页按重点、速记、数字摘要、普通记录安排视觉层级；正文不放装饰性大图。周／日历按 48 px／小时排布，重叠事项分栏，全天事项可单独滚动。年度习惯格按日期可补录；颜色深浅依据该周实际打卡次数。
