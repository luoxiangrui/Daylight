# Daylight 0.3.0 使用与迁移

安装包名为 **Daylight-0.3.0-Setup-x64.exe**。先在旧版设置里做一份完整备份，再退出旧程序。安装器使用当前用户的程序目录，首次启动时升级个人数据库。真实资料与程序文件分别存放。在 Windows 的已安装应用中可卸载；卸载只处理安装清单中的程序文件和指向本版的快捷方式。

## 数据保护

- 设置 → 自动备份：先选目录，选择每日或每周和保留份数（1–100），保存设置。应用运行时检查到期情况，完全退出期间不执行；下次启动后补做。自动备份保存在所选目录下的 Daylight-auto 子目录。成功产生并检查新快照后才清理旧份。失败原因显示在同一栏。
- 设置 → 从备份恢复：选择 SQLite 文件。确认框列出备份文件的修改时间、版本、记录数和分类数量。确认后先留存当前数据库，再替换；恢复结果包含原库副本位置。备份文件时间来自文件系统，复制工具可能更新该时间。
- 单个新附件最大 32 MiB。图片按格式检查；旧图片无法解码时，可在原记录重新添加原文件。设置 → 批量导出附件可单独带走文件。
- SQLite 从结构版本 1 顺序升级到 2、3。第三次迁移新增统一标签、标签关联、目标进度事件、完成日期和快速记录提交凭据。旧版的文件、重复任务、逐日勾选、草稿和历史节点保留。旧版已有的重复历史节点保留作原始记录；不会补造无法确定的旧目标完成日期。不要用旧版直接打开升级后的库。要退回旧版，请使用升级前备份。

## 日常操作

- **快速记录**：程序运行时按 Ctrl + Alt + J，或点击系统托盘 Daylight 图标。可创建日记、任务、学习记录或纪念日。若系统快捷键被占用，请使用托盘或设置里的「打开快速记录」。主窗口仍支持 Ctrl + N 新建和 Ctrl + K 搜索。
- **找回记录**：可用空格隔开多个词，结果必须同时匹配。按类型、起止日期、标签及排序缩小范围。点结果可回原文。标签的改名、颜色、合并和删除在设置中操作，会先显示关联记录及影响数量。
- **日历**：展开「显示内容」选择类别，软件会记住。拖动任务或事件到另一日，或在日视图拖到时间格。确认后生效，取消保留原安排。有相撞的时间段会提示。跨日安排使用结束日期；修改重复任务时请留意单日与后续范围。
- **日记**：可以直接写 Markdown，也可以切换富文本，用粗体、斜体编辑。选择照片，输入说明，点击「插入正文」。在 Markdown 中选择图片标记，可用「照片向前／向后」调整顺序。在设置里选择「Markdown 与附件」，得到索引、每篇手记以及 assets 文件夹。移动或分享时请带上整个导出目录。
- **学习与目标**：在学习计划旁点「记一次学习」会预填所属计划、科目和目标。按实际分钟数保存。学习页查看计划和实际时长；周、月回顾可以打开相应记录。目标保存或任务完成率变化时，只有进度变化才追加节点。
- **外观**：设置中的浅色、深色和跟随系统三种选项都可持久保存。
