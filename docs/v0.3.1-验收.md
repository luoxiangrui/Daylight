## 视觉检查与修复

逐组查看 1280×800、1440×900、1920×1080 的 16 视图对照图，放大检查周历。第一轮发现全天事件块继承了满高样式，跨入小时区域；修正为自适应高度并限制全天区滚动。速记移到首页焦点后，设置增加分组跳转，快速窗口宽屏居中。这些调整后重新采集全部截图并检查实际 PNG 尺寸及页面横向溢出。截图数据为隔离测试资料，内含 Windows 自带图片作为附件样本。

## 交付边界

已知密集排期时，周历同一时段的并排时间块会缩窄，可打开日视图或原记录查看全文。年度习惯是按日的二值打卡，色阶反映该周打卡次数。备份与导出文件包含明文私人记录。当前无签名，未对 GitHub 做发布或推送。
