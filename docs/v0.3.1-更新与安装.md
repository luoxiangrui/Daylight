# Daylight 0.3.1 · 更新与安装

先在旧版设置里保存一份完整备份，退出程序，双击 Daylight-0.3.1-Setup-x64.exe。使用原安装位置即可升级。版本沿用数据库结构 3，未添加或修改迁移。用户记录、草稿和附件仍在个人资料目录。

- 首页直接看到重点任务、完成率与速记。点「调整布局」后拖动模块，或在设置里显示、隐藏、上移和恢复默认顺序。
- 今日任务显示优先级、截止时间及状态，已完成项可以收起。任务详情仍支持逐日子任务。
- 周历与日历日视图按时长绘制，全天事项单列；重叠时分栏并提示，跨午夜事项在次日显示续段。
- 日记列表并列标题、正文开头、心情与照片。组合输入期间延后写草稿，提交文字后再保存。可以直接退出专注模式。
- 学习、目标树、习惯周／月／年、纪念日、周期回顾和设置均已调整。回顾的趋势来自本地记录，可从明细打开原项。
- 统一使用设置 → 文件导出 → 导出 Markdown 与附件。导出目录包括 index.md、各篇 Markdown 和 assets。要在另一台设备阅读，请复制整个目录。
- Ctrl K 搜索，Ctrl N 新增，应用运行时 Ctrl Alt J 打开快速记录；快捷键冲突时可从设置或托盘进入。当前本地交付未创建 GitHub Release。
