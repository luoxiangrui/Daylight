# Daylight 0.4.0 验收

## 基线与差异

分支 codex/v0.3.1 的工作树已有未提交改动，包括 v0.3.2 的日历标注。基线取 0.3.2 x64 安装包，已核对包内 package.json 和设置页版本。其 SHA-256 为 51C382B08B1FCFD56E30390CEC4EDEFE7A385567BF4B045A341F37594F640557。另一个旧工程对应无版本号安装包 0.2.0。仓内还保留 0.3.0 和 0.3.1 安装包。

本次沿用 Electron 37、原生 JavaScript、SQLite、受限预加载接口与既有资料目录；数据库由 3 升至 4。测试只使用临时目录及合成资料。
