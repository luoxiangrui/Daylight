# 0.3 开发核对

基线为独立仓库的 v0.2.0 标签，原有三项 Node 测试通过。在 codex/v0.3.0 本地分支实施。旧库、发布标签、真实资料及旧安装包均不作为测试写入目标。

|任务书条目|审计结果、改动位置与验证重点|
|---|---|
|3.1、3.2|db/store.cjs 只匹配日期外形，数值隐式转换，每次保存目标都会追加历史。补服务器端验证，保留既有历史行；比较实际进度。|
|3.3、3.4|main.cjs 的 VACUUM INTO 能创建一致快照，恢复仅检查部分表，文件替换中断存在缺口。需要备份预览、保留策略、恢复故障测试。|
|3.5|附件是 SQLite BLOB，正式附件有级联删除；未验证大小/文件名，草稿附件不随日记删除。加入边界与导出检查。|
|4|ui/app.js 显示来自数据库的内存记录，现有单关键词及种类筛选；标签是字段字符串，无统一身份。需要迁移旧标签、改名合并和影响预览。|
|5|Ctrl N、Ctrl K 已有。主进程无系统快捷键、托盘与独立快速窗口。注意重复提交和多窗口同步。|
|6|日历复用源记录，任务单日/后续版本在 tasks.js/dates.js 维护。旧拖动只排序。增加按类型过滤、跨日、时间冲突和可取消移动。|
|7|journal.js 保留草稿和待发布附件，publish 是事务。文字格式仅有 Markdown 预览，导出缺少文件。不可破坏粘贴、重启草稿、日历回原文。|
|8、9|学习有计划/实际和科目汇总，目标有手动/任务进度，周回顾有选图和下周计划。补日历区间汇总、历史和记录入口。|
|10、11|现有纸感浅深主题，无系统主题。每 30 秒提醒读取整个 state；同步读图、全状态刷新及长列表存在性能风险，需实测。|
|12、13|已有 Store、升级、窗口、重开、安装包解包冒烟测试。安装器无卸载或桌面快捷方式；窗口缩放测试不等于实际多屏。|
|安全边界|preload 是显式 IPC 白名单；主进程未单独核验调用窗口。备份选择器、路径及渲染器参数需要主进程校验。|

顺序：数据安全 → 搜索与标签 → 快捷记录、日历、日记 → 学习/目标/回顾 → 界面与性能 → 回归、安装和哈希。逐项结果见最终测试记录，未运行的检查不计通过。
