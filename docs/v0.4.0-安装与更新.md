# Daylight 0.4.0 · Windows x64

## 安装与回退

先在设置中创建完整备份，把文件留在安装目录之外。退出 Daylight，运行 Daylight-0.4.0-Setup-x64.exe。安装位置仍为当前用户的 %LOCALAPPDATA%\Programs\Daylight，开始菜单入口为 Daylight。打开设置底部可核对版本和架构。安装包旁的 .sha256 文件可与 PowerShell Get-FileHash 的结果比较。

原有 Electron userData 路径继续使用，数据库名为 daylight.sqlite。支持从结构 1、2、3 升级和打开结构 4。结构 4 新增 habit_days，事务提交后才提升版本号。旧习惯继续打卡，旧勾选保存在原表中。首次选择数量模式时自行填写单位和目标，已有打卡不会折算为分钟或次数。每个有记录的日子保留自己的单位、目标和实际量。

若要退回 0.3.2，先在 0.4.0 保存一份当前完整备份，再退出并安装 0.3.2。关闭所有 Daylight 进程后，将 userData 中的当前数据库及同名 -wal、-shm 文件（如有）保存在单独目录，把升级前的完整备份复制回原位置并命名为 daylight.sqlite。旧版只读得懂结构 1 至 3。回退后看到的是升级前备份时的记录，之后的修改留在新版备份中。

## 已实现

- 早晨打开首页，可添加第一项任务、挑选重点、查看下一步、完成或撤回。默认模块依次从重点、写下此刻、时间安排、进度和最近记录开始。已有布局继续生效。今日列表保留拖动，可用键盘选择「上移」。重复任务明确显示本次修改影响的日期，保存后仍停在原任务。
- 首页写下此刻沿用日记草稿。Ctrl+N 新增，Ctrl+K 搜索，程序运行时 Ctrl+Alt+J 或托盘打开独立快速记录。日记显示草稿、正式写入、成功、失败重试状态。展开后可插图、写说明、调整正文图片顺序；专注状态按 Esc 后焦点到保存按钮。
- 习惯选择「数量」，如「分钟」、目标 20。当天追加 12 和 8，两次合计 20；发现记错可选择改正当天合计。改正为 0 仍是一条记录。回顾按相同单位合计，各单位的达标天数按日期去重，同一日有至少一项该单位习惯达标即计一天。
- 学习计划内点「记一次学习」会带入计划、科目和目标，填写实际分钟后保存。展开「每次学习」可打开原记录。累计时长可超过计划，修改和删除会重算。

## 备份、导出和提醒

完整 SQLite 备份保留记录、附件、草稿、关联、偏好和提醒历史，可整库恢复。恢复前核对文件时间、结构版本和数量，完成后界面给出被替换数据库的副本位置。Markdown 导出用于阅读，包含日记、学习记录、索引和相对路径的 assets 附件目录。请一起移动整个目录。

提醒和自动备份依赖 Daylight 进程运行。完全退出时无后台通知；再次运行会从上次检查处补查，并按已触发历史去重。实际弹窗还受 Windows 通知权限影响。快捷键被占用时可使用应用内或托盘入口。

## 后续边界

年册、稍后提醒、免打扰、通用删除撤销和完整历史回放留到后续版本。删除撤销需要先确定附件、打卡、逐日数量和关联的恢复规则。历史回放需要先确定同一目标多次达成、回退及再次达成时的日期解释。
