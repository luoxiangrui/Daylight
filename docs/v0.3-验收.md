# Daylight v0.3.0 本地验收

**结论。** 当前版本可供 Windows x64 用户安装试用。下面按任务书列出实现与验证范围。“通过”指右栏描述的测试已经实际执行。“部分验证”指实现已接入正常使用入口，列出的边界仍需补验。设备比例测试和故障注入均单独标明。

|条目|状态|核对结果与证据|
|---|---|---|
|审计、基线与迁移纪律|已实现并通过测试|本地基线为 v0.2.0；对照独立仓库与历史 SQL，001、002 与标签没有差异。新增 003。所有启动测试均使用独立资料目录。|
|3.1 数据校验|已实现并通过测试|验证类型、标题、真实日期、时间、进度、对象结构、引用类型、循环目标、草稿归属、文件名与大小等。非法日期、标题、对象、目标引用、时间、大文件、伪装图片被拒绝。|
|3.2 目标历史|已实现并通过测试|目标建立写创建事件，同进度改名不追加；关联任务完成后累计进度从 0 到 100，只写一次进度事件。验证删除后外键与原历史保留。旧版重复保存产生的历史行仍可查阅。|
|3.3 自动备份|已实现但尚未完全验证|设置可选目录、每日／每周、保留份数，显示上次结果。已实测 WAL 快照、成功后轮换、失败保留旧文件；跨自然日、跨周的长期运行未实等。|
|3.4 恢复|已实现并通过测试|校验版本、必要表、完整性、外键、记录 JSON 和附件，显示文件时间与各类数量。用真实文件走通备份、删除、恢复。注入 ENOSPC 和替换后重开失败，原库可继续使用。真实磁盘占满或断电未实测。|
|3.5 附件|已实现但尚未完全验证|32 MiB 上限；图片格式边界检查，无法显示时给出重新添加原件提示；完整备份与批量导出。PNG/JPEG、超限、损坏文件、级联删除、草稿发布与导出字节均有测试。未穷举第三方编码器、连续多张最大尺寸图片。|

|4.2 标签|已实现并通过测试|迁移旧标签、统一建关联、改名、合并、删除并回写文本字段；影响范围和颜色可从设置查看。大小写去重采用 SQLite NOCASE。|
|5 快速记录|已实现但尚未完全验证|独立窗口可选任务、日记、学习、纪念日；提交凭据事务防重。实际窗口写入日记且主窗口可查，系统成功注册 Ctrl Alt J，保留 Ctrl N、Ctrl K。托盘点击、其他程序抢占快捷键、连续多次物理按键仍待人工检查。|
|6 日历与任务|已实现但尚未完全验证|月／周／日、类型开关、月格摘要、日时间轴、跨日区间和冲突提示。实际窗口拖动输入经日期／时间目标处理，取消保持原值，确认后平移并保留时长。原重复任务单日与后续修改已复验。跨月长事件、跨午夜重复系列的组合仍需更多边界测试。|

### 本次尚未完成的验收

- **未实现独立的硬件验收自动化**：真实双屏热插拔、逐屏 DPI、休眠唤醒、物理断电，以及整块磁盘耗尽。当前有渲染比例测试、逾期提醒测试、SQLite 故障注入及回滚测试。
- **尚未完全验证 Windows 交互安装**：当前用户安装、开始菜单、可选桌面快捷方式和卸载注册已实现。隔离解包／覆盖／启动／卸载已通过；未修改真实用户开始菜单或用个人数据库演练。
- **风险**：完整备份包含明文个人记录和附件，须自行保管；v0.3 数据库不能交给旧版本继续写。安装程序未做代码签名。自动备份和全局快捷键仅在程序运行时生效。

### 开发与复验入口

- docs/v0.3-核对.md 记录模块审计。db/003.sql、validation、maintenance、tags、progress、export 和 services 负责迁移与 P0/P1 数据操作。
- ui/find、calendar、rich、review，quick.cjs 和两个 preload 分别处理搜索／标签、日历、图文、报告和快速窗口。build 下包含安装、卸载及打包验证。
- npm test 执行数据库套件；npm run build 打包并执行安装目录桌面冒烟。tests/windows.cjs、reopen.cjs、volume.cjs 分别负责窗体／缩放、跨进程草稿恢复、真实窗口短测。桌面测试数据和示例附件均在独立目录创建。
